An entry for the [make.fun](https://make.fun) bounty
**"Sleeve Notes for the Frog Trio"** — one album title and a short back
cover blurb, up to 400 characters in total, for a jazz trio made entirely
of frogs.

The entry is titled **"Night Water"**. The blurb is written in the voice of
a record shop owner who has actually heard the trio play: the late set at
the boathouse on Miller's Pond, Milo's tenor sax sitting just behind the
beat, Ada walking the bass through the reeds, and Pip keeping time on
brushes so soft you can hear the water against the pilings between songs.
One night, no overdubs, the three of them in a circle. The frog premise is
played completely straight — three frogs are a working band.

## How to run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (pass a path as the first
argument to write elsewhere for local testing). The program is
**stdlib-only** — no third-party packages — and deterministic: no network
calls and no clock dependence, so running it twice produces the same text.
It also runs under `python3 -S` (no site-packages), the way the grader
runs it.
